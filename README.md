### Hi, I'm Ethan! 🔥😛

ECE @ Princeton. I like working right at the line between hardware and software: digital design, embedded systems, and lately on-device AI and the hardware that makes it run.

#### 🔨 Currently working on...
- **[EchoAssist](https://github.com/wen-ethan/EchoAssist)**: a real-time iOS captioning app with on-device speech recognition and speaker diarization, so no audio ever leaves the phone
- **[HoagieClub/help](https://github.com/HoagieClub/help)**: Hoagie Club's all-in-one academic app, built by Princeton students for Princeton students
- **Tinker (PURC)**: tech lead for Princeton's student hardware projects group

#### 📟 Recent projects
- **[serial-vga-display](https://github.com/wen-ethan/serial-vga-display)**: UART-controlled VGA character display on a Lattice iCE40 FPGA, written in Verilog

#### 🛠️ Tools I reach for
Swift · Verilog · TypeScript · JavaScript · Python · C
